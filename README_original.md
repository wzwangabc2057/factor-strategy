# Enhanced Multi-Factor Quantitative Strategy

多因子量化增强策略 - A股多因子选股与权重优化系统

## 策略概述

基于多因子模型的量化投资策略，通过因子打分和权重调整来优化持仓收益。

### 核心特性

- **12-14个因子体系**: ROE、股息率、PE估值、利润增速、动量、反转、低波动等
- **10档权重调整**: 根据综合得分动态调整个股权重
- **行业均衡约束**: 单行业权重不超过20%
- **止损机制**: 大盘止损、板块止损（可选）

## 止损机制 (v1.6+)

```
大盘止损规则:
├── 触发条件: 沪深300 < 250日均线
├── 动作: 仓位降至70%
├── 恢复条件: 沪深300 > 250日均线 × 1.02
└── 效果: 回撤改善5-6%
```

## 未来函数修复 (v1.7)

v1.0-v1.6 存在的未来函数问题:
1. 财务数据固定使用2024年报 → 回测期间使用了未来数据
2. PE/PB估值使用当前值 → 未使用历史时点数据
3. 因子得分固定不变 → 整个回测期间使用同一套因子

v1.7 修复方案:
```
时点数据获取规则:
├── 1-4月: 使用前年年报 (T-2年12月31日)
├── 5-8月: 使用上年年报 (T-1年12月31日)
├── 9-10月: 使用当年中报 (T年6月30日)
└── 11-12月: 使用当年三季报 (T年9月30日)

因子滚动更新:
└── 每年初重新计算所有因子得分
```
