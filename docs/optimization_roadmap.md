# 因子策略优化路线图

**目标**: 将年化收益从 15% 提升到 30%+

## 当前状态 (v1.7)

| 指标 | 值 |
|------|-----|
| 年化收益 | 14.66% (R4) / 16.61% (R5) |
| 最大回撤 | -15.68% (R4) / -19.77% (R5) |
| 因子数量 | 12-18 个 |
| 合成方式 | 线性加权 |
| 调仓频率 | 年度/季度 |

## 优化路线图

### Phase 1: 因子IC分析系统 (预期提升 +3~5%)

**参考项目**: [Alphalens](https://github.com/quantopian/alphalens)

**目标**: 验证每个因子的有效性，剔除无效因子

**关键指标**:
- IC (Information Coefficient): 因子值与未来收益的相关性
- ICIR: IC 的稳定性 (IC均值/IC标准差)
- Rank IC: 秩相关系数

**实现步骤**:
1. 对每个因子计算未来 N 日收益的相关性
2. 生成因子分层回测 (5层或10层)
3. 计算 IC 时间序列和月度 IC
4. 生成因子有效性报告
5. 基于 IC 筛选有效因子 (IC > 0.02, ICIR > 0.5)

**输出文件**:
- `src/analysis/ic_analyzer.py` - IC分析核心模块
- `src/analysis/factor_report.py` - 因子有效性报告生成

---

### Phase 2: 扩展因子库 (预期提升 +5~8%)

**参考项目**: [Qlib Alpha158](https://github.com/microsoft/qlib)

**目标**: 从 18 个因子扩展到 50+ 个有效因子

**新增因子类别**:

| 类别 | 因子 | 数据来源 |
|------|------|---------|
| 技术动量 | 5日/10日/20日/60日动量 | stock_data_qfq |
| K线形态 | KMID, KCLOSE, KSUMP, KSUMN | OHLC计算 |
| 波动率 | 20日/60日波动率 | 收益率标准差 |
| 换手率 | 换手率因子 | stock_data_qfq.huanshoulv |
| 估值 | PB, PS, EV/EBITDA | valuation_local |
| 质量 | 毛利率, 净利率, ROA | stock_financial |
| 成长 | 营收增速, 利润增速 | 同比/环比 |

**实现步骤**:
1. 实现 Alpha158 风格的技术因子计算
2. 添加质量/成长因子
3. 对所有因子进行 IC 分析
4. 筛选 IC > 0.02 的有效因子
5. 因子正交化 (去除高度相关因子)

**输出文件**:
- `src/data/alpha158_factors.py` - Alpha158 因子计算
- `src/data/quality_factors.py` - 质量/成长因子

---

### Phase 3: 机器学习因子合成 (预期提升 +5~10%)

**参考项目**: [Qlib LightGBM](https://github.com/microsoft/qlib)

**目标**: 用 ML 模型替代线性加权

**模型选择**:
- LightGBM: Qlib 默认模型，17.8% 年化
- XGBoost: 稳定性好
- CatBoost: 处理类别特征

**训练框架**:
```
数据划分:
├── 训练集: 前 3 年数据
├── 验证集: 第 4 年数据
└── 测试集: 第 5 年数据 (滚动)

特征工程:
├── 因子标准化 (行业中性化)
├── 缺失值处理
└── 特征选择 (基于 IC)

目标变量:
└── 未来 5日/10日/20日 收益率
```

**实现步骤**:
1. 构建训练数据集 (因子 + 标签)
2. 实现滚动训练框架
3. 训练 LightGBM 模型
4. 生成预测信号
5. 对比 ML vs 线性加权的回测结果

**输出文件**:
- `src/ml/feature_builder.py` - 特征工程
- `src/ml/model_trainer.py` - 模型训练
- `src/ml/rolling_trainer.py` - 滚动训练框架

---

### Phase 4: 回测验证与对比

**目标**: 验证每个阶段的改进效果

**对比维度**:
- 年化收益
- 最大回撤
- 夏普比率
- IC 均值/ICIR
- 换手率

**报告输出**:
```
阶段对比表:
┌─────────────┬──────────┬──────────┬─────────┬────────┐
│ 阶段        │ 年化收益  │ 最大回撤  │ 夏普    │ IC均值 │
├─────────────┼──────────┼──────────┼─────────┼────────┤
│ 基准 v1.7   │ 14.66%   │ -15.68%  │ 0.98    │ N/A    │
│ +IC筛选     │ ~17%     │ ~-15%    │ ~1.1    │ 0.03   │
│ +扩展因子   │ ~22%     │ ~-18%    │ ~1.3    │ 0.04   │
│ +ML合成     │ ~27%     │ ~-20%    │ ~1.5    │ 0.05   │
└─────────────┴──────────┴──────────┴─────────┴────────┘
```

## 风险控制

### 1. 过拟合风险
- 使用滚动训练 (walk-forward)
- 限制模型复杂度
- 交叉验证

### 2. 未来函数风险
- 严格使用时点数据
- 财务数据延迟处理
- 交易成本模拟

### 3. 数据质量风险
- Gate-0 数据可靠性检查
- 异常值处理
- 缺失值处理
